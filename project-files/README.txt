Вспомогательные материалы проекта Автопромойл

- guides/ — пошаговые инструкции владельцу.
- supplier/ — исходный прайс поставщика, проверочные таблицы и черновики допусков. Не импортировать данные в production без сверки и подтверждения.
- tools-partsapi/ — локальные скрипты проверки методов PartsAPI.
- archive-vps/ — холодный архив ранней VPS-версии. Не используется в production; сохранён для истории и восстановления полезных материалов.

Основные документы проекта находятся в docs/ и CLAUDE.md. Текущая production-архитектура описана в docs/ARCHITECTURE.md.
