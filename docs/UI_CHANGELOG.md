# UI Changelog — витрина Mini App

## 21.11.2026 — Главная и карточки товаров

**Статус:** согласовано по макетам, выкладка фронта.

### Цели
- Убрать визуальный «AI-shop» (цветная карусель, слабая иерархия).
- Подчинить экран DESIGN.md: Deep Navy `#101B4D`, Cyan `#00AFC7`, светлый фон.
- Вынести ценность «подбор масла» наверх.
- Сделать вязкость (5W-30 и т.п.) главным сканируемым полем на карточке.

### Главная (`index.html` + `css/styles.css` + `js/app.js`)
- Sticky-шапка: **логотип + «АВТОПРОМОЙЛ»** не заменяются названием раздела/товара.
- Порядок блоков: **Подобрать масло** → компактная промо-карусель → категории → сетка.
- Карусель: 3 слайда, высота ~132px, градиент navy/cyan, декоративная «волна», без green/orange/purple.
- Категории: чипы **без иконок** (только текст).
- Фон: белый + лёгкая blueprint-сетка (`rgba(16,27,77,0.03)`).

### Карточки и деталка (`js/products.js` + `css/styles.css`)
- Карточка: бренд → **крупная вязкость** → название → объём/статус → цена + компактная кнопка корзины (cyan).
- Обводка вместо тяжёлой тени, радиус 12px.
- Детальная страница: вязкость ~40px, чипы API/ACEA/объём (`#E5F7FA` / `#00707F`).
