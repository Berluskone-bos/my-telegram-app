# UI Changelog — витрина Mini App

## 21.11.2026 (c) — Карточка товара как на макете

### Проблема на проде
- Два блока «Характеристики» и «Дополнительно» с повторами (API, тип масла)
- «Применение» слипалось с текстом
- Шапка: дубль текста рядом с логотипом (если не задеплоен (b))

### Решение
- Один список характеристик без дублей (SAE=вязкость, повтор API/типа отфильтрованы)
- Крупная вязкость, чипы, цена, статус наличия
- Параметры списком label | value с переносом длинного текста
- Описание отдельным блоком ниже
- Кнопка «Добавить в корзину» navy; ссылка «Подобрать для своего авто»
- Шапка: только `img/logo.png`

### Файлы
- index.html
- css/styles.css
- js/products.js
- js/app.js


## 28.11.2026 — Автомобильная подложка: синхронизация mobile breakpoint
- Автотест админ-панели ожидал `@media (max-width: 760px)`, тогда как фактическое правило фонового слоя намеренно ограничено `600px`.
- Исправлено только ожидание теста: проверяется реальный breakpoint `600px`; CSS, визуальные параметры и поддержку светлой/тёмной темы не меняли.


## 28.11.2026 — Исправление пути фонового изображения админ-панели
- В admin.html фон запрашивается по /img/car-watermark.webp, но серверная статика обслуживает только STATIC_DIR (public/), тогда как ресурс находится в корневом img/.
- Добавлен точечный маршрут для выдачи только car-watermark.webp; другие файлы репозитория не открываются. Проверка и публикация выполняются через PR и CI.
