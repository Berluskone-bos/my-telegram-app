# UI Changelog — витрина Mini App

## 21.11.2026 (c) — Карточка товара как на макете

### Проблема на проде
- Два блока «Характеристики» и «Дополнительно» с повторами (API, тип масла)
- «Применение» слипалось с текстом
- Шапка: дубль текста рядом с логотипом (если не задеплоен (b))

### Решение
- Один список характеристик без дублей (SAE=вязкость, повтор API/типа отфильтрованы)
- Крупная вязкость, чипы, цена, статус наличия
- Параметры списком label | value с переносом длинного текста
- Описание отдельным блоком ниже
- Кнопка «Добавить в корзину» navy; ссылка «Подобрать для своего авто»
- Шапка: только `img/logo.png`
