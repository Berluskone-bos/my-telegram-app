## Найденные и исправленные баги (проект владельца)
- `esc` была объявлена в четырёх JS-файлах → `Identifier already declared`, сайт не работал в браузере. Оставлена одна в `products.js`.
- Сайт не отправлял `X-Telegram-Init-Data`, сервер отвечал 401 → заказы не сохранялись (`tg.sendData` не работает при запуске из меню). Исправлено, `sendData` убран.
- Пароль админки был вписан в `admin.html` (публичный репозиторий) → вход по `ADMIN_API_KEY`, проверка на сервере; админка не отправляла ключ и не работала с защищённым API.
- CORS не разрешал `PUT`/`DELETE` → админка не меняла статусы. Исправлено.
- Токены ботов были в истории Git, токен курьерского бота — в `setup-courier-bot.js`. Токены отозваны (02.11.2026), из кода убрано.
- XSS в админке (имена, адреса, комментарии) и в характеристиках товара. Закрыт через `esc()`; проверено тестом (7 срабатываний до, 0 после).
- Курьерские кнопки не проверяли владельца маршрута; webhook курьера принимал не тот заголовок и регистрировался без пути `/webhook/courier`; самостоятельно зарегистрированный курьер сразу активен; TLS к Neon без проверки. Исправлено.
- Pages публиковал весь корень репозитория (включая `bot/`). Теперь только `_site`.
