# АВТОПРОМОЙЛ — Telegram Mini App

Магазин автотоваров АВТОПРОМОЙЛ для Telegram.

## Быстрый старт

### 1. Создайте Telegram бота

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Укажите имя: `Gulf Western Oil Shop`
4. Укажите username: `gulf_western_shop_bot` (или любой свободный)
5. Скопируйте полученный токен

### 2. Настройте бота

```bash
cd bot
npm install
```

Создайте файл `.env` в корне проекта (и `bot/.env` для бота):
```env
BOT_TOKEN=ваш_токен_от_botfather
ADMIN_CHAT_ID=ваш_chat_id
WEB_APP_URL=https://your-domain.com
WEBHOOK_URL=https://your-domain.com/webhook
WEBHOOK_SECRET=случайная_строка_32_символа
ADMIN_API_KEY=случайная_строка_32_символа
COURIER_BOT_TOKEN=ваш_токен_курьер_бота
ADMIN_BOT_TOKEN=ваш_токен_админ_бота
DATABASE_URL=postgresql://user:pass@neon.tech/neondb?sslmode=require
PORT=3000
```

**Безопасность (проверено):**
- Админка открывается с сервера: `https://gulf-bot-production.up.railway.app/admin`. Вход по ключу `ADMIN_API_KEY` один раз; дальше сессия в HttpOnly-cookie (SameSite=Strict, 12 ч / 2 ч без действий), журнал действий — вкладка «Журнал». Ключ в браузере не хранится, заголовок `x-admin-key` не принимается
- `courier-bot.js`: проверка секрета вебхука (`verifyWebhookSecret`); админские маршруты защищает `verifyAdmin` из `bot/admin-auth.js`
- `.env.example`: добавлены `WEBHOOK_URL`, `WEBHOOK_SECRET`, `ADMIN_API_KEY`, `COURIER_BOT_TOKEN`, `ADMIN_BOT_TOKEN`
- `TRUST_CLIENT_PRICES` по умолчанию `false` (цены из БД, не клиента)

Чтобы узнать свой Chat ID:
1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Отправьте любое сообщение
3. Скопируйте ваш Chat ID

### 3. Запустите локально

**Вариант A: С ngrok (для тестирования в Telegram)**

```bash
# Терминал 1: Запустите веб-сервер
cd gulf-western-shop
python -m http.server 3000

# Терминал 2: Запустите ngrok
ngrok http 3000

# Терминал 3: Запустите бота
cd bot
node bot.js
```

**Вариант B: Только локально (в браузере)**

```bash
cd gulf-western-shop
python -m http.server 3000
```

Откройте http://localhost:3000

**База данных:** подключение к Neon (`DATABASE_URL` с `sslmode=require`); `db.js` поддерживает SSL для `railway` и `neon`. При локальном запуске без БД запустится, но команды с БД (`/orders`, `/routes`) не сработают — нужна работающая `DATABASE_URL`.

### 4. Настройте Mini App в Telegram

1. Скопируйте HTTPS URL из ngrok (например: `https://abc123.ngrok-free.app`)
2. Обновите `WEB_APP_URL` в `bot/.env`
3. Перезапустите бота
4. Откройте вашего бота в Telegram
5. Отправьте `/start`
6. Нажмите кнопку "Открыть магазин"

## Функции приложения

- 🛒 Каталог с фильтрацией по категориям
- 🔍 Поиск по названию и характеристикам
- ⭐ Сортировка (цена, рейтинг, популярность)
- 📦 Детальная страница товара
- 🛍 Корзина с изменением количества
- ❤️ Избранное
- 👤 Профиль с бонусной системой
- 🚚 Форма заказа с доставкой
- 📲 Уведомления в Telegram
- 🎁 Бонусы и реферальная программа (код `REF-<Telegram ID>`, +200 ₽ приглашающему, оплата бонусами до 20 % товаров)
- 🗺 Маршрут курьера из нескольких заказов: кратчайший порядок по дорогам с поправкой на час пик (живых пробок нет), время приезда каждому клиенту и обновление при сдвиге
- 🧭 Админ-панель с боковым меню: Заказы, Доставка, Товары, Клиенты, Аналитика, Журнал; сворачивается в полосу иконок, значки (новые заказы, в пути), поиск по заказам (Ctrl+K), удобна на телефоне
- 🕐 В шапке админки — часы по московскому времени и календарь на месяц (клик по часам); кнопки светятся при наведении
- 📊 В админке: доска заказов по колонкам (Новые → Подтверждены → Сборка → В пути → Доставлены; кнопка следующего шага или перетаскивание) и график заказов и выручки за месяц с выбором периода — назад до начала продаж, «С начала продаж», свои даты
- 🧩 Интерактивные карточки Telegram (Bot API 10.4): трекер заказа с оценкой звёздами у клиента, маршрутный лист у курьера, сводка дня у админа (`/summary`)

## Интерактивные карточки (виджеты Telegram)

Карточка — маленькая страница внутри чата, которую бот меняет без новых сообщений. Работает только в личных чатах.

> **Статус на 16.11.2026:** Telegram пока отклоняет карточки от обычных ботов (`INPUT_MEDIA_WIDGET_NOT_ALLOWED`), поэтому сейчас всё работает обычными сообщениями. Бот сам пробует снова раз в несколько часов — когда Telegram разрешит, карточки включатся без вмешательства.

| Кому | Карточка | Что показывает |
|------|----------|----------------|
| Клиенту | Трекер заказа | шаги «Принят → Собираем → В пути → Приехал → Доставлен», курьер, время приезда, звёзды оценки после доставки |
| Курьеру | Маршрутный лист | рейс, сколько точек сделано, адрес, время и статус каждой точки |
| Админу | Сводка дня (`/summary`) | заказов и сумма за сегодня, сколько новых, в сборке, в пути, доставлено, отменено; обновляется сама |

Карточка не даёт уведомления на телефон, поэтому «Курьер приехал», «Доставлен», отмена и время приезда по-прежнему приходят обычным сообщением.
**Выключатель:** переменная Railway `WIDGETS_ENABLED=0` возвращает обычные сообщения (без переменной — карточки включены). Если Telegram не примет карточку, бот сам отправит обычное сообщение. Подробности — `docs/TASKS.md` (обновление 27) и `docs/ARCHITECTURE.md`.

## Переменные окружения сервера (Railway)

Секреты (токены ботов, ключи, база) хранятся только в Railway Variables и в репозиторий не попадают. Полный список — в `docs/ARCHITECTURE.md`. Для доставки и карточек важны:

| Переменная | Для чего |
|------------|----------|
| `WAREHOUSE_ADDRESS` (или `WAREHOUSE_LAT` + `WAREHOUSE_LON`) | склад — откуда курьер стартует; без неё старт — центр Санкт-Петербурга |
| `SERVICE_MINUTES` | минут на выдачу заказа на каждой точке (по умолчанию 5) |
| `ETA_UPDATE_MINUTES` | на сколько минут должно сдвинуться время, чтобы клиенту написали повторно (по умолчанию 15) |
| `OSRM_URL` | сервис дорог (по умолчанию бесплатный `router.project-osrm.org`) |
| `WIDGETS_ENABLED` | `0` — выключить интерактивные карточки |

## Тесты

```
npm install
TEST_DATABASE_URL=postgres://postgres@localhost:5432/t npm test
```
Тесты с базой стирают данные и работают только с локальной базой с именем `t`, `test` или `*_test` (рабочие базы блокируются). Без `TEST_DATABASE_URL` такие тесты пропускаются.

### Свой сервер

```bash
# Установите nginx
sudo apt install nginx

# Скопируйте файлы
sudo cp -r * /var/www/html/gulf-western/

# Настройте nginx
sudo nano /etc/nginx/sites-available/gulf-western
```

Конфигурация nginx:
```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    root /var/www/html/gulf-western;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://localhost:3000;
    }
}
```
