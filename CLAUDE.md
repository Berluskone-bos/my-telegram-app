# Автопромойл — инструкции для Claude

Перед любой задачей прочитай все файлы из `docs/` (PRD, ARCHITECTURE, RULES, DESIGN, TASKS, MEMORY) и ссылайся на них. Исходные документы владельца: `docs/ТЗ_с_дополнениями.docx`. Вспомогательные файлы (инструкции, прайс, скрипты PartsAPI) — в `project-files/`.

- Этот файл и папка `docs/` лежат в том же публичном репозитории, что и код (Mini App + боты; GitHub Pages, Railway, Neon). Сайт публикуется только из `_site`, документы на сайт не попадают, но на GitHub видны всем. Цены владелец не считает тайной; токены, пароли, ключи и персональные данные клиентов в репозиторий не кладём никогда.
- Работай по одной задаче из `docs/TASKS.md`; после неё отметь статус и допиши итог в `docs/MEMORY.md`.
- Владелец не программист: объясняй по-русски, пошагово, с блоками «что вы должны увидеть».
- Не выдавай написанное за проверенное: различай «написано», «проверено на тестовой копии», «проверено на живом сервисе».
- Секреты только в переменных Railway / `.env`. Не проси у владельца пароли и токены.
